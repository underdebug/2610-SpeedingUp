## Technical Overview

Implements a **Position-Based Dynamics (XPBD) cloth solver fully on the GPU using CUDA**.
Supports both **Jacobi** and **Gauss–Seidel–style** constraint solving through configurable solve passes.
Uses **parallel constraint batching** to maximize GPU occupancy while maintaining stability.
Mouse interaction is handled via **GPU-based triangle raycasting**, enabling interactive cloth dragging.
Collision handling includes **sphere** and **ground plane** constraints.
Surface normals are computed on the GPU for rendering.
Designed with **persistent device buffers** to avoid per-frame allocations and improve performance.

## How to Run

### Linux / VS Code

Install the CUDA toolkit, CMake 3.24+, a C++17 compiler, OpenGL/GLU,
FreeGLUT, GLEW, GLM, and Boost (chrono, thread, program_options) development packages.
Running requires a working NVIDIA driver and a graphical desktop.

Open this folder in VS Code with NVIDIA Nsight Visual Studio Code Edition installed:

* **Ctrl+Shift+B** configures and builds the Debug executable.
* **F5** builds and launches it using the **CUDA-GDB** configuration.
  The alternative **GDB** configuration supports CPU debugging with the C/C++ extension.

The VS Code build task selects `/usr/local/cuda-13.0` and CUDA architecture 89
for this machine's RTX 4050. This avoids the unsupported PTX generated by the
newer default CUDA 13.4 installation. Adjust those task arguments when moving
to a different machine.

For a terminal build:

```sh
cmake -S . -B build -DCMAKE_BUILD_TYPE=Debug
cmake --build build --parallel
./build/CUDAClothXPBD
```

### Windows / Visual Studio

**Environment:** Visual Studio 2019

**Dependencies (NuGet):**

* glfw 3.4.0
* glm 1.0.2
* glew.v140 1.12.0
* freeglut.3.0.0.v140 1.0.2

**External (Non-NuGet)**
- Boost C++ Libraries (tested with Boost 1.82)


Build and run the solution from Visual Studio.
